# Aarvak Diagnostics

Lovable Prompt — Exact Website Replication

Source Website:
https://www.aarvakdiagnostics.com/

Objective:
Recreate this website exactly as it is inside Lovable. This is currently running on custom code and needs to be fully migrated and recreated inside Lovable with 1:1 accuracy.

Core Instructions

Lovable must replicate the entire website as a carbon copy.

Do NOT redesign, reinterpret, optimize, or improve anything.

This must be a pixel-perfect, action-perfect replication.

Everything should match exactly as on the live site.

Mandatory Requirements

Page Replication

Crawl and identify every page on the site

Recreate each page inside Lovable

Maintain identical URL structure

Maintain same page hierarchy

Design Fidelity

Fonts must match exactly

Colors must match exactly

Spacing and layout must match exactly

Button styles must match exactly

Mobile responsiveness must match exactly

Assets

Download and store all images locally inside Lovable

Do NOT hotlink images from the source site

Copy all icons, graphics, and visual elements

Animations & Effects

Replicate every scroll effect

Replicate hover effects

Replicate transitions and animations

Replicate menu behaviors

Functional Elements
Copy all functionality including:

Forms

Buttons

Navigation menus

CTA actions

Contact forms

Any popups

Any embedded widgets

Content

Copy all text content exactly

Copy all headings exactly

Copy metadata if available

Mobile Version

Replicate the mobile layout exactly

Maintain same breakpoints and behavior

Performance

Ensure the recreated version loads smoothly

Maintain the same user interaction flow

Strict Rules

Lovable must not apply its own design intelligence.

Do NOT:

Change layout

Improve UI

Modify colors

Change fonts

Rearrange sections

Rewrite content

This is strictly a 1:1 replication exercise.

Final Deliverable

A fully working Lovable project that mirrors the live website exactly, including:

All pages

All design elements

All effects

All interactions

All assets hosted locally

The result should feel like an exact clone of the original site but fully editable and manageable inside Lovable.
